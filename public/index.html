    Lint check

    ESLint проверяет JavaScript, Prettier — форматирование.

    npm run lint

    Tests

    npm test
    ЛОГИКА

    Build project

    Создаёт самостоятельную сборку приложения в dist/.

    npm run build
    СБОРКА

    Check README

    Проверяет, что README содержит слово project.

    grep "project" README.md
    ДОКУМЕНТАЦИЯ
  5. 05

    Smoke check

    Запускает готовую сборку и делает HTTP-запросы.

    npm run smoke
